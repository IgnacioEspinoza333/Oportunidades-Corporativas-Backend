# Oportunidades-Corporativas-Backend


# 1. Backend y base de datos

Servidor Spring Boot ejecutándose y conectado a una base de datos operativa.


Microservicios requeridos implementados, con endpoints REST funcionales.


Operaciones CRUD integradas según las funcionalidades del proyecto.


Datos almacenados persistentemente; no depender exclusivamente de listas en memoria.


Entidades y relaciones coherentes con las reglas de negocio.


Validación de datos y manejo adecuado de errores en el backend.


Comprobación de operaciones desde la aplicación móvil.


# 2. Aplicación Android

Proyecto Kotlin y Jetpack Compose que compila y se ejecuta correctamente.


Corrección de observaciones de evaluaciones anteriores de UI/UX, arquitectura y lógica.


Pantallas, navegación y formularios funcionales y coherentes con el caso.


Formularios con validaciones y retroalimentación visual.


Arquitectura MVVM con responsabilidades identificables (Screen, ViewModel, UiState, Repository, Model).


Integración mediante Retrofit con los microservicios propios.


Operaciones de consulta, creación, modificación y eliminación según las reglas del negocio.


Estados visuales de carga, éxito y error cuando corresponda.


Conservación de las funcionalidades de EA2, incluyendo recursos nativos y persistencia local donde corresponda.
